# Java-BasicATM
 ATM System 💳

📌 About the Project

This is my first Java project. It is a simple ATM simulation developed using Java. It allows users to perform basic banking operations through a console interface.

🚀 Features

* Check Balance: View your current account balance.
* Deposit Money: Add money to your account.
* Withdraw Money: Withdraw money from your account.
* Exit: Close the program.

🛠️ Technologies Used

* Java
* Scanner Class
* If / Else If Statements
* Basic Mathematical Operations

⚙️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or Eclipse.
3. Make sure Java is installed.
4. Compile the program:
    javac ATM.java
5. Run the program:
    java ATM

🎯 Project Goal

The goal of this project was to practice Java fundamentals, improve my programming skills, and understand how conditional statements and user input work in a real-world example.
